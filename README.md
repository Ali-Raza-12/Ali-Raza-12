## Featured Projects

### AI Apply Assist — Job Application Automation Platform
> MERN Stack · Groq API · Gemini API · Vite · Tailwind CSS

A full-stack AI-powered platform that eliminates the repetitive work of job applications. Users upload their CV once — the system extracts key sections, generates a tailored professional email for any job description, and tracks every application to prevent duplicates.

**Key features:**
- AI email generation using Groq + Gemini APIs, contextualised to CV and job description
- CV section extraction with PII removal before saving
- Application history log with HR contact and company tracking
- Secure JWT authentication with HTTP-only cookies

### Stock & Market Intelligence Platform
> Next.js 14 · TypeScript · MongoDB · Finnhub API · Gemini AI · Tailwind CSS v4

A real-time market intelligence SaaS built on Next.js 14 App Router. Integrates live stock data, AI-generated market insights, and automated email summaries — all behind a secure, role-protected dashboard.

**Key features:**
- Real-time stock search and watchlist via Finnhub API
- AI market analysis using Google Gemini
- Automated email digests via Inngest background jobs
- Embedded TradingView charts with mobile-first responsive UI

### AI Resume Screening System
> Next.js · Python · Flask · Sentence Transformers · NLP · PDF Parsing

An AI-driven recruitment tool that ranks candidates against a job description using semantic similarity — going beyond keyword matching to understand contextual relevance.

**Key features:**
- Sentence Transformers + cosine similarity for semantic candidate scoring
- Custom NLP pipeline extracts skills, experience, education from raw PDFs
- Batch multi-resume upload with colour-coded ranked results
- Next.js frontend + Python Flask backend
